已完成从原对齐版完整第115轮续训至150的35轮，以及最终150检查点的固定512×3面板评测。300轮离线回放、42项CPU测试、真实保存与重载、逐轮门控和完整检查点核验均通过。用户提出的探索性效果目标未全部达到；具体结果如下。

区间先在每个任务内平均三次解码，再对512个任务簇进行10,000次配对bootstrap，固定种子20261109。原始终止页面和配对统计在本地独立复算，共4608条记录，其中3072条为未修改的既有基线轨迹。

## 实现与核验

- E：格式异常或语义noop的辅助项归零，退出信用桶；保留两种观测标签，不改变动作执行或原生奖励。
- N：已确认的可执行item/detail→home/results返回导航完全中性，delta/raw/centered/token注入均为零，并切断该处辅助GAE传播。
- B：已终止的可执行Buy Now在全败组中辅助项归零并退出桶，原生奖励与GiGPO优势按原实现计算。
- 全败指组内没有完全成功，仍可能取得部分任务分数。任务分数取值0–1；训练沿用原生成功奖励10、失败奖励0和系数0.1的格式惩罚。
- 三项各有独立开关；本次GPU实验同时启用三项。关闭开关时与冻结基准完全一致。候选状态解析、历史统计与非全败组处理保留原契约。
- 两份各150轮真实轨迹完成离线回放。旧版轨迹使用对齐版核心，是反事实回放，不是原旧版算法的重现。原10,247个格式异常非noop中的4,019个正辅助信用归零；格式有效noop的正信用598个归零（原审计740减重叠142，粘贴文本中的594不符）。返回与终止购买的辅助项也严格归零，有效动作仍有非零信用。
- 新训练4480条轨迹的任务ID、文本和顺序与原对齐版逐条一致。实际门控共2439个actor行、284428个响应token，非零门控token为0。
- 116完整保存后实际重载，并完成117更新；优化器、随机状态、数据游标、128个训练和128个验证环境状态、方法历史均核验。前三名按验证成功率排序，同分取较后轮次；另保留最新完整状态和115/116诊断点。最终受保护文件全量哈希通过。

## 结论边界

这是单训练种子、晚期35轮续训、三个机制联合干预，且使用已有开发面板。不能据此断言单个机制的因果贡献、训练种子稳健性或未见任务泛化。离线归零与运行正确性不等于性能改进。原生验证与固定面板分开报告；本次原生150验证为185/256，任务分数0.834313。
